## 元件說明

### 1. Controllers Component (控制器元件)
- **檔案位置**: `src/controllers/`
- **主要類別**: `PassportRecognitionController`
- **職責**:
  - 作為系統的門面 (Facade)
  - 協調 Models 和 Parsers 元件
  - 提供高階 API 給應用層使用
  - 管理提示詞範本
- **對外介面**:
  - `recognize_passport()` - 完整辨識流程
  - `recognize_passport_raw()` - 僅辨識不解析
  - `get_default_prompt()` - 取得預設提示詞

### 2. Interfaces Component (介面元件)
- **檔案位置**: `src/interfaces/`
- **主要介面**: 
  - `IImageRecognizer` - 影像辨識器介面
  - `IResponseParser` - 回應解析器介面
- **職責**:
  - 定義契約 (Contract)
  - 實現依賴反轉
  - 提高可擴展性和可測試性
- **設計模式**: Strategy Pattern (策略模式)

### 3. Models Component (模型元件)
- **檔案位置**: `src/models/`
- **主要類別**: 
  - `ImageRecognizer` - 影像辨識實作
  - `ImageSizeError` - 自訂異常
  - `ImageNotFoundError` - 自訂異常
- **職責**:
  - 處理圖片讀取和驗證
  - 與 Gemini API 互動
  - 執行影像辨識
- **外部依賴**:
  - `google-generativeai` - Gemini API SDK
  - `pathlib` - 檔案路徑處理
  - `base64` - 圖片編碼

### 4. Parsers Component (解析器元件)
- **檔案位置**: `src/parsers/`
- **主要類別**:
  - `ResponseParser` - 回應解析實作
  - `PassportInfo` - 資料類別
- **職責**:
  - 解析 LLM 回應文字
  - 支援多種格式 (JSON、鍵值對)
  - 提供結構化資料
- **外部依賴**:
  - `json` - JSON 解析
  - `re` - 正則表達式
  - `dataclasses` - 資料類別

### 5. Application Layer (應用層)
- **檔案**: `example.py`
- **職責**:
  - 提供使用範例
  - 展示 API 使用方式
  - 初始化系統元件

## 元件間通訊方式

### 1. 依賴注入 (Dependency Injection)
- Controller 透過建構函式接收 IImageRecognizer 和 IResponseParser
- 降低耦合度，提高可測試性

### 2. 方法呼叫 (Method Invocation)
- Controller 呼叫 Recognizer 的 `recognize()` 方法
- Controller 呼叫 Parser 的 `parse()` 方法

### 3. 資料傳遞 (Data Transfer)
- 使用 `PassportInfo` dataclass 作為資料傳輸物件 (DTO)
- 字串格式的影像路徑和提示詞作為參數傳遞

## 可擴展性設計

### 1. 新增不同的辨識引擎
實作 `IImageRecognizer` 介面，例如：
- `GPT4VisionRecognizer` - 使用 OpenAI GPT-4 Vision
- `ClaudeVisionRecognizer` - 使用 Anthropic Claude Vision

### 2. 新增不同的解析策略
實作 `IResponseParser` 介面，例如：
- `XMLResponseParser` - 解析 XML 格式
- `CSVResponseParser` - 解析 CSV 格式
- `StructuredResponseParser` - 使用結構化輸出

### 3. 新增不同的控制器
針對不同的證件類型建立專門的控制器：
- `IDCardRecognitionController` - 身分證辨識
- `DriverLicenseRecognitionController` - 駕照辨識
