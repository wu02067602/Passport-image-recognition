# 護照辨識系統 - 序列圖

本文件展示護照辨識系統的執行流程與物件互動。

## Flask API 護照辨識流程

```mermaid
sequenceDiagram
    participant Client as HTTP 客戶端
    participant API as Flask API<br/>(app.py)
    participant Service as PassportService
    participant Analyzer as VisionAnalyzer
    participant GAPI as Gemini API
    participant Parser as ResultParser
    
    Client->>API: POST /api/passport/recognize
    Note over Client,API: {"image": "BASE64_STRING"}
    
    API->>API: 驗證請求格式與必要欄位
    
    API->>Service: recognize_from_base64(base64_image)
    
    Note over Service: 解碼 BASE64
    Service->>Service: base64.b64decode(base64_image)
    
    Service->>Analyzer: analyze_all_fields_from_bytes(img_bytes)
    
    loop 對每個護照欄位
        Analyzer->>GAPI: generate_content([prompt, image])
        GAPI-->>Analyzer: response_text
    end
    
    Analyzer-->>Service: raw_results (dict)
    
    Service->>Parser: parse_all_fields(raw_results)
    Parser-->>Service: passport_data
    
    Service-->>API: passport_data
    
    API-->>Client: JSON Response<br/>{"success": true, "data": {...}}
```

## 批次處理護照辨識流程

```mermaid
sequenceDiagram
    participant User as 使用者
    participant Main as main.py
    participant Batch as PassportBatchProcessor
    participant Controller as PassportController
    participant Analyzer as VisionAnalyzer
    participant Parser as ResultParser
    
    User->>Main: 執行批次處理命令
    Note over User,Main: --input ./passports --output results.csv
    
    Main->>Batch: __init__(model_name)
    Batch->>Controller: 建立 PassportController
    
    Main->>Batch: process_directory(input_dir, output_csv)
    
    Batch->>Batch: scan_directory(input_dir)
    Note over Batch: 遞迴掃描目錄<br/>找出所有圖片檔案
    
    loop 對每個圖片檔案
        Batch->>Batch: process_single_image(image_path)
        Batch->>Controller: recognize_passport(image_path)
        
        Controller->>Analyzer: analyze_all_fields(image_path)
        Analyzer-->>Controller: raw_results
        
        Controller->>Parser: parse_all_fields(raw_results)
        Parser-->>Controller: passport_data
        
        Controller-->>Batch: passport_data
        Batch->>Batch: 寫入 CSV
    end
    
    Batch-->>Main: 處理完成
    Main-->>User: 顯示結果統計
```

## 完整護照辨識流程

```mermaid
sequenceDiagram
    participant User as 使用者
    participant Controller as PassportController
    participant Encoder as ImageEncoder
    participant Analyzer as VisionAnalyzer
    participant Templates as PromptTemplates
    participant API as Gemini API
    participant Parser as ResultParser
    
    User->>Controller: recognize_passport(image_path)
    
    Note over Controller: 1. 驗證圖片
    Controller->>Encoder: get_mime_type(image_path)
    Encoder-->>Controller: mime_type
    
    Note over Controller: 2. 分析所有欄位
    Controller->>Analyzer: analyze_all_fields(image_path)
    
    loop 對每個護照欄位
        Analyzer->>Templates: get_prompt(field)
        Templates-->>Analyzer: prompt_template
        Analyzer->>API: generate_content([prompt, image])
        API-->>Analyzer: response_text
    end
    
    Analyzer-->>Controller: raw_results (dict)
    
    Note over Controller: 3. 解析結果
    Controller->>Parser: parse_all_fields(raw_results)
    
    loop 對每個欄位結果
        Parser->>Parser: parse_llm_response(response)
        Parser->>Parser: extract_value(parsed)
    end
    
    Parser-->>Controller: passport_data (dict)
    Controller-->>User: 結構化護照資料
```

## 單一欄位辨識流程

```mermaid
sequenceDiagram
    participant User as 使用者
    participant Controller as PassportController
    participant Encoder as ImageEncoder
    participant Analyzer as VisionAnalyzer
    participant Templates as PromptTemplates
    participant API as Gemini API
    participant Parser as ResultParser
    
    User->>Controller: recognize_single_field(image_path, field)
    
    Note over Controller: 1. 驗證圖片
    Controller->>Encoder: get_mime_type(image_path)
    Encoder-->>Controller: mime_type
    
    Note over Controller: 2. 分析指定欄位
    Controller->>Analyzer: analyze_field(image_path, field)
    Analyzer->>Templates: get_prompt(field)
    Templates-->>Analyzer: prompt_template
    Analyzer->>API: generate_content([prompt, image])
    API-->>Analyzer: response_text
    Analyzer-->>Controller: raw_result
    
    Note over Controller: 3. 解析並提取值
    Controller->>Parser: parse_llm_response(raw_result)
    Parser-->>Controller: parsed_result
    Controller->>Parser: extract_value(parsed_result)
    Parser-->>Controller: field_value
    
    Controller-->>User: 欄位值
```

## 錯誤處理流程

```mermaid
sequenceDiagram
    participant User as 使用者
    participant Controller as PassportController
    participant Analyzer as VisionAnalyzer
    participant API as Gemini API
    
    User->>Controller: recognize_passport(image_path)
    Controller->>Analyzer: analyze_all_fields(image_path)
    
    alt 圖片不存在
        Analyzer-->>Controller: FileNotFoundError
        Controller-->>User: FileNotFoundError
    else 圖片無法開啟
        Analyzer-->>Controller: ValueError
        Controller-->>User: ValueError
    else API 呼叫失敗
        Analyzer->>API: generate_content()
        API-->>Analyzer: Error
        Analyzer-->>Controller: RuntimeError
        Controller-->>User: RuntimeError
    else 解析失敗
        Controller->>Parser: parse_all_fields()
        Parser-->>Controller: ParseError
        Controller-->>User: ParseError
    end
```
